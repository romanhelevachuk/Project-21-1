# CS2 Statistics Platform

A web platform for collecting, processing, and visualizing Counter-Strike 2 player statistics.

## Project Structure

- `frontend/` - React + Vite frontend application
- `server/` - Node.js + Express backend server

## Color Scheme

- Gold-Yellow (#FFCC00) - Accents, buttons, icons
- Graphite (#121212) - Alternative background, footer
- White (#F5F5F5) - Text, statistics blocks background
- Positive Green (#84CC16) - Positive indicators (wins)
- Negative Red (#EF4444) - Negative indicators (losses)

## Setup Instructions

### Frontend

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Backend

1. Navigate to the server directory:
   ```bash
   cd server
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Development

- Frontend runs on: http://localhost:5173
- Backend runs on: http://localhost:3000
